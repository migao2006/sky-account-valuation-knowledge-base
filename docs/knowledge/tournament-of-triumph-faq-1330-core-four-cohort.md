# Tournament of Triumph FAQ 1330 core-four cohort

This replayable cohort records only four Tournament of Triumph 2024 FAQ 1330 entries: Tournament Curls, Tournament Torch, Tournament Golden Garland, and Tournament Tunic. It intentionally excludes Tournament Headband.

FAQ 1330 establishes each entry's historical cost and the 2024-07-29 through 2024-08-18 PDT event window. The pinned SkyGame-Data snapshot independently supplies vendor title, GUID, and type. The cohort creates no set or bundle, and does not assert current availability, permanent ownership, formal Traditional Chinese names, visual identity, first release date, or model eligibility.

Replay with `python tools/normalize/apply_tournament_of_triumph_faq1330_core_four_cohort.py --apply`; ordinary verification runs without `--apply`.
