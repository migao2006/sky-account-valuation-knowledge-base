# 估價方法

P0 是「可比帳號選擇器」，不是把物品價格相加的報價表。它以帳型、季節結構、物品與套組、完成度、地圖、資源、綁定、任次、日期和證據品質選擇透明的同類案例。

## 分池與相似度

先排除服務、收購、混價及多帳資料，再依單帳、相容帳型家族、伺服器／幣別證據及價格型態分池。輸入已明示 TWD／國際服時，幣別或伺服器未知的案例不會進入同一價格池。相似度總分 100：帳型 15、季節 22、物品與套組 20、地圖 10、收藏結構 8、資源 7、綁定 6、任次 4、日期 5、證據 3。

估價器讀取 `data/comparables/accounts.jsonl`，其中每筆都由 history 與對應 account profile 合併，因此季節矩陣、已映射物品、套組聲稱、資源與逐平台綁定是實際評分欄位，不是輸出裝飾。文字只提到套組但未證明完整時只形成 `mentioned_unverified`，不得升級為完整套組。

少於三筆同一精確帳型時，只能明示擴張到相同帳型家族（例如永久無翼與未細分無翼）；不得跨到有翼、簡號或其他不相容帳型。若仍不足，回傳 `insufficient_comparables` 和擴張歷程，不產生價格區間。

## 價格與證據

刊登、急售、最後公開、已售聲稱和可驗證成交各自獨立。已售聲稱不是成交。未知資料不補值；綁定風險是獨立維度，不能取代帳號內容分類。
